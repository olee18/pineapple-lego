## ຄວາມສາມາດ

- 2 ພາສາ: ລາວ (ຄ່າເລີ່ມຕົ້ນ) / ອັງກິດ
- ໂໝດກາງເວັນ / ກາງຄືນ (ດວງເດືອນ ດາວ ແມງໄຟ ໄຟປະດັບ)
- ທີມຄຣິສມາສ (ປຸ່ມ 🎄): ຫິມະຕົກ ພື້ນຫິມະ ໄຟສີແດງ-ຂຽວ-ຄຳ ເປີດເອງຊ່ວງ 1 ທັນວາ – 6 ມັງກອນ
- ໂໝດຖ່າຍຮູບ ມີລາຍນ້ຳ "for Nuttaya ♡" ໃນມືຖືບັນທຶກລົງຄັງຮູບຜ່ານເມນູແບ່ງປັນ
- ຫຼິ້ນອອບລາຍໄດ້ (PWA) ແລະ ບັນທຶກສະຖິຕິເວລາ/ດາວໄວ້ໃນເຄື່ອງ

## ເປີດຫຼິ້ນໃນເຄື່ອງ

ບໍ່ຕ້ອງ build ຫຍັງ

```bash
python3 -m http.server 8765
```

ແລ້ວເປີດ http://localhost:8765

## Deploy (Cloudflare Pages)

- Framework preset: **None**
- Build command: *(ປະວ່າງໄວ້)*
- Build output directory: `/`
- Production branch: `main`

## ໄຟລ໌ຫຼັກ

| ໄຟລ໌ | ໃຊ້ເຮັດຫຍັງ |
| --- | --- |
| `index.html` | ໜ້າເວັບ, ໜ້າຕ່າງຕ່າງໆ |

| `i18n.js` | ຄຳແປ ລາວ / ອັງກິດ (ໂຄດຂຽນເປັນພາສາໄທ ທຸກຂໍ້ຄວາມໃໝ່ຕ້ອງເພີ່ມຄຳແປຢູ່ນີ້) |
