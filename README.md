# Pineapple Lego

by Viengnakhone

เกมเว็บ 3 มิติ ต่อดอกไม้จากบล็อกสไตล์เลโก้ เลือกชิ้นส่วนจากถาด แตะจุดเรืองแสง แล้วดูดอกไม้ค่อย ๆ ประกอบจนบาน
พอต่อเสร็จ โดมแก้วจะครอบลงมาบนฐานไม้

## ด่าน

| ด่าน | ดอกไม้ | ระดับ | ขั้น |
| --- | --- | --- | --- |
| 01 | ทานตะวัน | เริ่มต้น | 8 |
| 02 | ทิวลิป | ง่าย | 8 |
| 03 | เดซี่ | ง่าย | 8 |
| 04 | กุหลาบ | ท้าทาย | 8 |
| 05 | ช่อดอกไม้ (แจกัน + 4 ดอก + ลาเวนเดอร์ + ดอกยิปโซ) | มาสเตอร์ | 8 |

## ความสามารถ

- 3 ภาษา: ลาว (ค่าเริ่มต้น) / ไทย / อังกฤษ
- โหมดกลางวัน / กลางคืน (พระจันทร์ ดาว หิ่งห้อย ไฟประดับ)
- โหมดถ่ายรูป มีลายน้ำ "for Nuttaya ♡" บนมือถือบันทึกลงคลังรูปผ่านเมนูแชร์
- เล่นออฟไลน์ได้ (PWA) และบันทึกสถิติเวลา/ดาวในเครื่อง

## เปิดเล่นบนเครื่อง

ไม่ต้อง build อะไร

```bash
python3 -m http.server 8765
```

แล้วเปิด http://localhost:8765

## Deploy (Cloudflare Pages)

- Framework preset: **None**
- Build command: *(เว้นว่าง)*
- Build output directory: `/`
- Production branch: `main`

## ไฟล์หลัก

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าเว็บ, หน้าต่างต่าง ๆ |
| `styles.css` | หน้าตาทั้งหมด |
| `game.js` | ตัวเกม 3D (Three.js r152) |
| `i18n.js` | คำแปลไทย / อังกฤษ / ลาว (คีย์คือข้อความภาษาไทย) |
| `sw.js` | แคชสำหรับเล่นออฟไลน์ |
| `vendor/three.min.js` | Three.js |

> หลังแก้ไฟล์ ให้เพิ่มเลข `?v=` ใน `index.html` และ `CACHE` ใน `sw.js` ไปพร้อมกัน ผู้เล่นจะได้เวอร์ชันใหม่ทันที
